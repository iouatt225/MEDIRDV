# Règles du Projet MediRDV CI

- **Commits automatiques** : L'agent de développement doit effectuer automatiquement un commit git en respectant la convention Conventional Commits, et ce **après chaque modification ou petite tâche complétée**. Immédiatement après chaque commit, l'agent **doit effectuer un `git push`** pour envoyer les modifications sur le dépôt distant (github.com:iouatt225/MEDIRDV.git).
